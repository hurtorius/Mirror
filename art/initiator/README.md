# Initiator model sources

The Blockbench files, textures, geometry data and runtime profile are the editable
sources for the Initiator. The complete base, crystal and rings are rendered in
world, item and preview views. Runtime assets are checked in under
`src/main/resources/assets/mirror`; no asset generator is required to build.

The geometry and profile tests read the original authoring files to check the
renderer against the model. Original artwork is MIT licensed; see
`docs/MERGED-SOURCE-LICENSE.txt` at the repository root.
